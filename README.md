# Transporte de Enfermos

Sistema completo para gestão e mobilidade de pacientes, com frontend e backend integrados.

## Descrição
Este projeto visa facilitar o transporte de pacientes e a gestão de recursos de saúde, promovendo eficiência e segurança no atendimento.

## Funcionalidades
- Cadastro e gerenciamento de pacientes
- Controle de veículos e equipes
- Roteirização inteligente
- Relatórios e dashboards

## LGPD
Este sistema foi desenvolvido em conformidade com a Lei Geral de Proteção de Dados (LGPD), garantindo a privacidade e segurança das informações dos pacientes.
