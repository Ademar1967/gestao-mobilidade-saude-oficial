Política de Privacidade

Esta Política de Privacidade descreve como os dados pessoais dos pacientes são coletados, utilizados e protegidos pelo sistema de Gestão de Mobilidade em Saúde, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

1. Coleta de Dados

Os dados pessoais coletados são utilizados exclusivamente para fins de transporte e atendimento em saúde, incluindo nome, idade, endereço, telefone, informações clínicas e dados de contato.

2. Uso dos Dados

Os dados são utilizados para agendamento, organização logística, comunicação com pacientes e responsáveis, e para garantir a segurança e eficiência do transporte em saúde.

3. Compartilhamento

Os dados podem ser compartilhados apenas com equipes de saúde, motoristas, profissionais autorizados e órgãos públicos, quando necessário para o atendimento.

4. Segurança

Adotamos medidas técnicas e administrativas para proteger os dados pessoais contra acesso não autorizado, perda, alteração ou divulgação indevida.

5. Direitos do Titular

O paciente ou responsável pode solicitar a qualquer momento: acesso, correção, exclusão ou portabilidade dos dados, bem como revogar o consentimento para uso dos dados pessoais.

6. Dúvidas e Contato

Para dúvidas sobre esta política ou solicitações relacionadas aos dados pessoais, entre em contato com a equipe responsável pelo sistema.

Última atualização: maio de 2026
