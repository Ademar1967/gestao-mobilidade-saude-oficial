How to import a patient list into the system
  1. You will receive the patient data file by email, WhatsApp, Google Drive, or another digital channel. The file is usually in Excel (.xlsx) or CSV (.csv) format.
  2. Download the file to your computer. Save it in an easy-to-find folder, such as "Downloads" or "Documents".
  3. Access the patient transport system.
  4. In the patient registration or listing menu, click "Import patients".
  5. Select the file you saved on your computer and confirm the upload.
  6. Wait for the import confirmation. The system will show a success message or indicate any file errors.
Export patient list:
  • To share or archive data, click "Export patients (Excel)" or "Export patients (CSV)" above the form.
  • The file will be downloaded to your computer and can be shared with other departments, colleagues, transport staff, administrative control, or used for personal backup.
  • You can send the file by email, WhatsApp, Google Drive, or another digital method, according to your workflow needs.
  • Excel format (.xlsx) is ideal for spreadsheet editing. CSV format (.csv) is compatible with most systems and can be imported easily.
Tips:
  • Make sure the file contains all required columns (name, age, phone, address, etc.).
  • If you are unsure about the file format, ask the support team for a sample template.
  • If you receive the file in a different format, convert it to Excel or CSV before importing.
