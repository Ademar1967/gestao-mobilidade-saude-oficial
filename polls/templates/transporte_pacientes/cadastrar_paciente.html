Como importar uma lista de pacientes no sistema
  1. Você receberá o arquivo com os dados dos pacientes por e-mail, WhatsApp, Google Drive ou outro meio digital. O arquivo geralmente estará no formato Excel (.xlsx) ou CSV (.csv).
  2. Baixe o arquivo para o seu computador. Salve-o em uma pasta fácil de localizar, como “Downloads” ou “Documentos”.
  3. Acesse o sistema de transporte de pacientes.
  4. No menu de cadastro ou listagem de pacientes, clique na opção “Importar pacientes”.
  5. Selecione o arquivo que você salvou no computador e confirme o envio.
  6. Aguarde a confirmação de importação. O sistema mostrará uma mensagem de sucesso ou informará se houver algum erro no arquivo.
Exportar lista de pacientes:
  • Para compartilhar ou arquivar os dados, clique em “Exportar pacientes (Excel)” ou “Exportar pacientes (CSV)” acima do formulário.
  • O arquivo será baixado no seu computador e pode ser enviado para outros setores, colegas, responsáveis pelo transporte, controle administrativo, ou para backup pessoal.
  • Você pode enviar o arquivo por e-mail, WhatsApp, Google Drive ou outro meio digital, conforme a necessidade do seu fluxo de trabalho.
  • O formato Excel (.xlsx) é ideal para edição em planilhas. O formato CSV (.csv) é compatível com a maioria dos sistemas e pode ser importado facilmente.
Dicas:
  • Certifique-se de que o arquivo contém as colunas necessárias (nome, idade, telefone, endereço, etc.).
  • Se tiver dúvidas sobre o formato do arquivo, peça um modelo para a equipe de suporte.
  • Caso receba o arquivo em outro formato, converta para Excel ou CSV antes de importar.
How to import a patient list into the system
  1. You will receive the patient data file by email, WhatsApp, Google Drive, or another digital channel. The file is usually in Excel (.xlsx) or CSV (.csv) format.
  2. Download the file to your computer. Save it in an easy-to-find folder, such as "Downloads" or "Documents".
  3. Access the patient transport system.
  4. In the patient registration or listing menu, click "Import patients".
  5. Select the file you saved on your computer and confirm the upload.
  6. Wait for the import confirmation. The system will show a success message or indicate any file errors.
Export patient list:
  • To share or archive data, click "Export patients (Excel)" or "Export patients (CSV)" above the form.
  • The file will be downloaded to your computer and can be shared with other departments, colleagues, transport staff, administrative control, or used for personal backup.
  • You can send the file by email, WhatsApp, Google Drive, or another digital method, according to your workflow needs.
  • Excel format (.xlsx) is ideal for spreadsheet editing. CSV format (.csv) is compatible with most systems and can be imported easily.
Tips:
  • Make sure the file contains all required columns (name, age, phone, address, etc.).
  • If you are unsure about the file format, ask the support team for a sample template.
  • If you receive the file in a different format, convert it to Excel or CSV before importing.
